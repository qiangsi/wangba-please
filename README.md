# 网吧，PLEASE · 请出示你的身份证

Papers, Please 风格的像素小游戏：2026 年「绿盾严打周」，你是**毛豆电竞网吧**的夜班网管小陈，坐在收银台查证件、找矛盾、盖公章，揪出拿家长身份证来上网的小学生。

▶ **在线试玩**：<https://maodou-wangba.pinme.dev>

## 玩法

- 喇叭叫号 → 旅客递证（身份证 / 会员卡 / 支付凭证），拖到桌上查验
- `§` 查看当天《护网公约》新规；`?` 检查模式点两处信息找矛盾，或点 Ta 说的话找马脚
- 测谎暗号：《孤勇者》接歌词、找蓝翔、V 我 50——一接就露馅；成年人只会一脸懵
- 第 4 天起 `X` 光扫书包：《五三》、57 分试卷、红领巾……在校生无所遁形
- 盖「准予 / 拒绝」后把证件拖回窗口还给旅客；判错吃警告单，第二次起罚款
- 六天剧本：放学快剪、翻墙大军（点击拦截）、铁蛋六天连环闯关——第 6 天他恰好满 18 岁
- 下班结算：猫粮、二舅药费、侄子的新皮肤；欠费查封；双结局

## 运行

双击 `index.html` 即可游玩（或用任意静态服务器托管）。手机横屏可玩，进度自动存在浏览器里。

## 技术

- 纯前端 HTML + Canvas（640×360 像素风），**零依赖、零构建**，全部代码约 3000 行
- 角色立绘是字符画网格定义的像素画（`js/gfx.js`），音效全部由 WebAudio 程序合成（`js/sfx.js`）
- 游戏日历锚定开局当天：第 1 天 = 玩家开始游玩的真实日期；铁蛋的生日 = 第 6 天
- 画面、代码、剧本均为原创；玩法向 Lucas Pope《Papers, Please》致敬

## 目录结构

```
index.html      页面外壳（横屏提示、静音/全屏按钮）

js/sfx.js       WebAudio 合成音效
js/docs.js      证件与纸张：身份证/会员卡/支付凭证/公约手册/警告单
js/data.js      剧本数据：角色、测谎暗号、矛盾定义、六天旅客队列
js/booth.js     检查台玩法：拖拽/盖章/检查/测谎/X光/事件
js/screens.js   开场/标题/报纸/结算/结局 + 日期天气牌
js/main.js      场景切换、输入分发、主循环、背景预渲染
```
